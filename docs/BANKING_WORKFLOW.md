# Banking Workflow

## Customer

1. Register or log in.
2. View own profile and accounts.
3. Transfer between allowed accounts.
4. Apply for a loan.
5. View loan status and transaction history.
6. Pay active loans from owned accounts.

## Employee

1. Log in with employee credentials.
2. Manage branch customers.
3. Open accounts.
4. Process deposits and withdrawals.
5. View branch transactions.
6. Help customers apply for loans.

## Manager

1. Log in with manager credentials.
2. Review branch accounts and employees.
3. Approve or reject loans.
4. View branch reports.
5. Freeze or activate accounts inside branch scope.

## Admin

1. Manage all branches.
2. Manage all customers and employees.
3. View global reports.
4. Review audit logs.
5. Demonstrate full database governance.
